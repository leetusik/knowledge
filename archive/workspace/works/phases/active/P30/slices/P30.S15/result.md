- **The reader's memory** (`components/reader/use-reading.ts`, called by `reader-frame.tsx`):
  - the resume: for a started chapter on its newest version with no hash, scrolls to the mapped block (or the fraction) with the chrome shown and raises the pill; a language-switch link whose section is missing lands on the mapped `resume`;
  - the cadence, a first write on open (the row goes `unopened` → `started`), the end sentinel finishing a member's chapter once, a hold lifted when the end leaves the view, `pagehide`/`visibilitychange` beacon, and the last sample for in-app navigation;
  - `mark(finished)` and `flush()`.
- **Writes:** `lib/reader/actions.ts` → `saveReaderPosition` (server action: `getSession()`, a strict zod body, `PUT /app/reader/positions` through the existing `putReaderPosition`); the beacon is the existing S8 route. The state read is new: `getReaderChapter` / `getReaderDoc` (`GET /app/reader/chapters|docs`) and `docStem` in `lib/knowledge/reader.ts`.
- **Data** (`lib/reader/load.ts`, `types.ts`): `view.write`, `view.progress` (state, finished version, max fraction, `resume`), `view.versions` (history rows, or `ok: false`), the next chapter's `n` and lede. The extra reads run in parallel and degrade (none can fail the page).
- **Chapter end** (`chapter-end.tsx`, a client component closing `ReaderArticle`, the `data-end` sentinel): the four member sentences in one grid cell (three `visibility: hidden`), the signed-out sentence and the raised Sign in to save (`SignInToSave`, finally mounted), next / last / loose blocks, "In this book" with the count and the same `ChapterList`. - **Version history** (`version-list.tsx`, the frame's `versions` panel: right sheet, focus to Close, Escape/Close/scrim, focus back to the opener): lead, rows newest first, Current tag, "Reading now", `View` → `?v=N` (newest clears it), "Unavailable".
- **Language switch:** flushes the pending position, then `?lang=&#section`.
- **Page `<title>`:** `generateMetadata` on the chapter page and the id and pretty document pages, sharing one load per request with the page through React `cache`.
- `ReaderPage` keys the frame by document and version (the hold, pill and position state end with the view).
