Component — Plain Markdown image

A plain Markdown image, ![alt](asset:name), inside a paragraph. It follows the figure's image rules (its own pixel size or smaller, the hairline edge, the reserved box) but carries no caption, credit or width, takes the id img-<name> rather than one an author writes, and sits at a paragraph's spacing; its alt text is its only text. An image never sits among words: the paragraph around it splits in two.
