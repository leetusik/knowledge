The figures at the three reference sizes

One prototype state drawn three times, in the signed reader. A click in any frame moves all three. Each frame carries the state bar at the top of its page, so it scrolls away with the chapter; a state, a theme or a text size picked in any frame shows in all three. The iPad in landscape (1024 × 768) is not drawn: from 40rem up the column is 36rem and every row lays out as at 820.
