Component — Sources list and citations

A sources list (```sources) and the citations that point at it. Each item reads in one order: number, title, publisher · date · Accessed, the URL as a link in its own words, the note, then the way back. A citation keeps the author's words and adds the source's number; following it marks the item, and the item's back links return to each citation. A source's URL opens the in-canvas note for a link that leaves the canvas.
