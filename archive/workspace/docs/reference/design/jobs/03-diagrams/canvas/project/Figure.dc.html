Component — The figure in the slot

A diagram is a figure in the text column: its title above it in the interface face, the drawing on the page itself (no plate, no frame), and its caption under it in the reading face, both at the column’s small step. Nothing else surrounds it. A drawing wider than the column keeps its size and scrolls in its own box, with the fades and the hint the code block uses.
