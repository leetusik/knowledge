Component — The frame’s own states: loading, a slow relay, a missing file, a failed relay, not found

Each state fills the frame’s area under the reader’s bars, which stay usable. Loading draws the document’s outline (still under reduced motion), and the slow line replaces it in place. A missing file and a failed relay each say what happened and the one thing to do. Not found reads the same for a missing address and a private one (404, never 403).
