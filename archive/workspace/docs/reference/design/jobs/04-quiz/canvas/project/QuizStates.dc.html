Component — Quiz block

The block in the reading column: a mono label naming it a quiz and how many questions it holds, the title when it has one, then the questions between hairlines. Each number hangs in its own column and is circled when the answer is right and struck through when it is wrong; the head counts the questions answered, never a score. Signed out, the reader answers and grades exactly as a member does, and Sign in to save opens once, under the first answer.
