Component — Table

Tables use the interface face at a step below the text and take the text column's width, the same two edges as the paragraphs. A table wider than the column scrolls sideways inside a focusable box that says so, at every width. A long table keeps its header row in view: on the page while it fits the column, inside its own box when it does not. Numbers are right-aligned as the source's alignment row asks.
