The book page at the four reference sizes

One prototype state drawn four times, each frame the whole page from top to bottom, so every part a preset names is in view: a preset or a click in any frame moves all four. On the device, the screen shows the frame’s top 844, 1180, 768 or 900 px; the top bar stays pinned while the page scrolls under it (board 05 draws its scrolled state). The state bar above the frames scrolls away with the board.
