Loose document row

A loose document is a row, never a card, so it can never pass for a one-chapter book. It carries the reader’s state words (Not started, Started · N%, Finished), its date, UPDATED when it changed since you finished it, ORIGINAL LAYOUT when it is legacy, and its project only outside its project’s shelf. No version numbers, and nothing that implies a series.
