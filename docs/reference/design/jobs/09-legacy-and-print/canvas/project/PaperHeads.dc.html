Component — The masthead and the colophon

The masthead opens page 1: where the sheet comes from (the book and the chapter’s place), the address that always opens it, the version and its date, and the print date. An older version says so before the title. The colophon closes the last page: where and when it was printed, which version it is, and where the current one lives. Crops of the page at 100%, inside the paper’s side margins.
