Component — Selection bar

It opens under a selection (above it when there is no room below; 28px below on touch, clear of the handles). One bar, four cases: a passage takes a highlight or a note; a heading or a typed block’s caption takes a note on its section or a bookmark; the title and the text before the first section take nothing yet; a plain Markdown document takes only a position bookmark. The buttons keep their width when they turn on.
