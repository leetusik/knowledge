Component — SVG block

The svg block draws one SVG from the S2 allowlist in currentColor (the text's ink) and the tone classes kb-fill- and kb-stroke-, with no frame of its own. Its label is its accessible name (role img); the caption shows under it when there is one. Its text is set in the interface face; strokes keep 1 px at every width.
