# Phase P41-sr: Listen: a free AI voice reader

_Intent: see [intent.md](intent.md)._

## Objective

Add a Listen control to the web reader that reads a document, or a whole book chapter after chapter, aloud in English or Korean with a free AI voice (a free API or a free model, chosen by ear from samples), playable on the operator's phone with the screen off; it skips quizzes, code and source lists, and reads a visual's text alternative instead of skipping it when the document has one.

  - **Read:** title, summary, headings, paragraphs, each list item, quote and callout paragraphs (callout
    title first), table body rows as "header: cell; …" (kind `table-row`, so the player can skip them),
    a figure, figures, diagram or svg's alt, label or title then its caption, and a formula's alt,
    reading and "sym: means".
  - **Skipped:** code, hr, quiz, sources, glossary.
  - **Inline:** math becomes linear text; an inline image reads its alt (P41-sr.S1).
