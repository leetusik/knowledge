### `skills_parity.py`

- **AGENTS (FAIL)** parses the markers. It fails on any of these:
  - a malformed, nested, duplicated or unclosed marker;
  - a `with=` name that is undefined;
  - a missing role or agent file;
  - a stray agent file;
  - a `name:` that differs from the file name;
  - `permissionMode`, `hooks` or `mcpServers` in the frontmatter;
  - `Agent` or `Task` in tools;
  - a body that differs from the brief;
  - a `pagetext` extract that does not compile.
- **`--write-agents`** regenerates the bodies and keeps the frontmatter.
- The docstring and PASS line are updated. CI is unchanged: `plugin-ci.yml` already runs the script, and no new script was added.
- Only lines that start with `<!-- part-b:` count as markers, so B0's prose can quote the marker text.
