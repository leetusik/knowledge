# Phase P38-e1: Right-size explain runs (plugin 0.9.0)

_Intent: see [intent.md](intent.md)._

## Objective

Cut a knowledge:explain run's cost to what the document needs: a delta mode that reuses a recent prior's verified evidence; a research team sized by the document's word budget (top tier for books only); verify only the claims the outline uses; the critic on another model, sampling sources instead of re-opening all; the writer held to its section budgets; a KB resolver that never prints the API key; a metered cost line with a cheaper option in the confirmation. Ships as plugin 0.9.0.
