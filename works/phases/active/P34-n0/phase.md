# Phase P34-n0: Keep private documents off the public repo

_Intent: see [intent.md](intent.md)._

## Objective

Stop the knowledge server from committing and pushing private projects' documents to the public GitHub repo (today it decides by owner account, not by project visibility), deal with what is already exposed there, and keep private titles out of the published home index.
